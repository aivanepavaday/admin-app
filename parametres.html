Compte & synchronisation

Connecté avec votre compte Google. Vos données sont synchronisées en temps réel entre tous vos appareils via Firebase.

Sécurité & confidentialité
  • Votre clé API est stockée uniquement dans votre navigateur (localStorage)
  • Les conversations sont envoyées uniquement à l'API Anthropic
  • Vos documents sont synchronisés de façon privée via Firebase (liés à votre compte Google)
  • Ne partagez jamais votre clé API et ne déployez pas cette app publiquement
